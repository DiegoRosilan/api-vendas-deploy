# GestorPDV.Financeiro

Contas a receber/pagar, parcelas, baixas, juros, multas e renegociação
(RN-FIN-*, RN-CLI-001).

A implementar na **Fase 7**: `CalculaPagamentos`, `FinalizaFormaPagamento`,
cálculo de juros/multa por atraso, `Renegocia` e a regra de bloqueio de
cliente inadimplente (`bloquear_venda_dias_vencido`).

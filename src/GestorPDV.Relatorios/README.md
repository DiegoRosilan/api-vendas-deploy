# GestorPDV.Relatorios

Integração com FastReport para relatórios de vendas, estoque, financeiro,
fiscal e impressões, lendo diretamente do PostgreSQL.

A implementar na **Fase 8** (relatórios) e **Fase 9** (impressão). Requer a
referência ao pacote/DLL do FastReport (licenciado) a ser adicionada no
Visual Studio — não incluída neste repositório.

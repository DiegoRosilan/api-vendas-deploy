# GestorPDV.Vendas

Motor de cálculo e fluxo de venda/pré-venda/orçamento/pedido/devolução/
cancelamento (RN-VEN-*, RN-ORC-001, RN-PED-001, RN-CAN-001).

A implementar na **Fase 6**: `CalculaItemTotal`, `CalculaSubTotal`,
`CalculaTotal`, `CalculaDesconto`, `CalculaAcrescimo`, `CalculaPrecoVenda`,
`CancelarVenda`, integração com `GestorPDV.Estoque` (baixa de estoque) e
`GestorPDV.Fiscal` (tributação por item).

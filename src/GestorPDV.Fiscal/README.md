# GestorPDV.Fiscal

Motor tributário: ICMS, ICMS-ST, PIS, COFINS, IPI, ISS, DIFAL, FCP, IBS/CBS,
CFOP e emissão de NFC-e/NF-e (RN-FIS-*).

A implementar nas **Fases 6/8**: `CalculaIcms`, `CalculaIcmsST`,
`CalculaPisCofins`, `CalculaIBS_CBS`, `RetornaCFOP`,
`VerificaSeCalculaDIFAL`, além da integração com o ambiente de emissão
(homologação/produção) e controle de numeração de documentos fiscais.
